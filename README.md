# agentic-human-ai-interaction
Course project for Agentic Human-AI Interaction (WiSe 26/27).

## What you build in the exercise 
A day and travel planner that works with a simulated calendar, timetable, weather service and notes. No real accounts, no personal data. - “Get me to my 14:00 meeting in Stuttgart on Thursday by train, and remind me to take an umbrella if it rains.” 
First a single tool call, then a task in several steps, more tools, plan preview with approval, a context trigger and retrieval. 
After each session, one successful run is saved there as a log file

## Conditions
1. Direct execution: The agent carries out its plan right away. You see the result.
2. Plan preview with approval: The agent shows its plan first. You approve, change or stop it before anything happens.
